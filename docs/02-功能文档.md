## 2. 问数主链路

### 2.1 状态取值（前端与审计共用）

| status | 含义 | 用户看到 | 是否写入会话历史 |
|---|---|---|---|
| `ok` | 成功执行并返回结果 | 答案 + 表格/图 + SQL 折叠区 | 是 |
| `rejected_by_intent` | 与数据分析无关，拒答 | 固定话术：「抱歉，我只解答与企业数据分析相关的问题。您可以试试：按单位统计学籍数量。」 | 否 |
| `missing_field` | 语义层里没有能回答该问题的列 | 「当前数据里没有可以回答该问题的字段：<原因>」 | 否 |
| `blocked_by_guard` | 护栏拒绝执行（写操作/多语句/系统表/部门取值非法） | 「[blocked_by_guard] <护栏原因>」 | 否 |
| `exec_error` | 自愈次数用尽后仍失败 | 「[exec_error] <引擎错误>」 | 否 |
| `engine_error` | 流水线未捕获异常（含 LLM 超时/未配置/空响应） | 「[engine_error] <repr>」 | 否 |

审计里另有 `unknown`，只在结果 dict 缺 status 时兜底出现。

### 2.2 界值一览

| 项 | 值 | 配置 |
|---|---|---|
| 单次问题长度 | 1~500 字 | 请求体校验，超长 422 |
| 结果行数上限 | 1000 | `QUERY_ROW_LIMIT` |
| 查询超时 | 10s | `QUERY_TIMEOUT` |
| LLM 单次超时 | 60s | `LLM_TIMEOUT` |
| LLM 单次输出上限 | 8192 tokens | `LLM_MAX_TOKENS` |
| 自愈重试轮数 | 2 | `SELF_CORRECT_RETRIES` |
| 召回 | 表 5 个、列 30 个 | `schema_link.link` |
| 宽表进提示词的列数 | 阈值 40 列，超过则最多 50 列 | `prompt_builder` |
| 会话标题 | 60 字（取问题前缀） | `sessions.TITLE_MAX` |
| 上下文窗口 | 最近 5 个 ok 轮 | `SUMMARY_KEEP_TURNS` |
| 触发摘要压缩 | ok 轮次 ≥ 8 | `SUMMARY_MIN_TURNS` |
| 摘要长度 | ≤ 800 字 | `memory.refresh` |
| 会话列表 | 最多 50 条 | `sessions.list_for(limit=50)` |
| 部门单位码数量 | 1~50 | `guard` |
| 实值探查返回值 | ≤ 50 个 DISTINCT | `/api/meta/probe` |
| 落库 payload 行数 | 200（实时响应仍是 1000） | `pipeline._save_turn` |
| 同步任务并发 | 1（进程内互斥，重复触发 409） | `meta_sync.start_async` |
| 同步进度轮询 | 前端每 2s 一次 | `App.vue syncMeta` |
| 指标名长度 | 1~128 字，唯一（重名 409） | `/api/metrics` |
| 全局码表编码 | 字母/数字/下划线 1~64 位，唯一 | `/api/code-dicts` |

### 2.3 回答文案规则

- 0 行：「查询完成，但没有符合条件的数据（可能受部门权限限制）。」
- 指标卡（单行单数值）：直接给 `列名=值`。
- 其余：「共 N 行（已截断至上限）?, 已生成<柱状图/折线图/饼图/表格>。」
- 附加提示（独立一行）：「敏感列已脱敏：<列>」「码值已翻译为含义：<列>」。

## 3. 图表推荐

显式指定优先于启发式（`chart_recommend.explicit_type`）：
饼图/扇形图→pie，折线图/曲线图/线图/趋势图→line，柱状图/柱形图/条形图/直方图→bar，表格/列表→table。
显式指定要落地还需满足形状条件：pie 必须正好 1 个类别列 + 1 个数值列；结果无数值列时任何显式图型都退回表格。

无显式指定时的启发式：
1. SQL 无聚合或结果为空 → 表格；
2. 非分组查询且行数≠1 → 表格；
3. 首列像时间且存在数值列 → 折线图（"像时间"要求值形如 `2026`/`2026-05`，裸 4 位数只有列名含时间语义词——年/月/日/期/季度/date/time/year/month/day/_dt/_rq/_ny/xn/_qm——且落在 1900~2100 时才算年份，避免 4 位单位码被误判成年份而随机出折线图）；
4. 单类别 + 单数值且问题含"占比/比例/分布/构成" → 饼图，否则柱状图；
5. 单行单数值 → 指标卡；
6. 其余 → 表格。

前端只对**最后一条消息**渲染 ECharts 画布（表格/指标卡只出表格）；表格视图最多显示 50 行，导出 CSV 是全部行（实时轮 ≤1000，历史回放轮 ≤200）。

## 4. 多轮与追问

- 改写规则：继承历史里的时间、指标、维度与过滤条件，只替换用户明确改变的部分；最新问题本身已自包含且无指代时保持原样，不会叠加历史的维度或图型。
- 追问会看到"上轮实际执行的 SQL 与结果列"，因此"再按专业拆一次""换个条件看"会沿用同一批表列名，减少字段幻觉。
- 纯换图追问（如「用饼图展示」「换成折线图吧」）走确定性通道，不请求 LLM 判意图：把上一轮问题取出、去掉旧图型后缀、拼上新图型。空历史时不接管，按普通问题处理。
- 只要求换图/重绘上一轮结果仍算 `data_query`，不会被当闲聊拒答。

## 5. 权限与数据安全的可观测表现

行级权限：
- 部门配了 N 个单位码 → 护栏注入 `别名.dept_col IN ('a','b',…)`；1 个 → 等值 `= 'a'`。子查询/CTE 里每张配了部门列的表都会被注入。
- 表未配 `dept_column` → 该表不裁剪（语义管理页必须逐表设置；新同步的表默认未设置）。
- 管理员令牌查询 → 完全不注入部门条件。
- 普通用户所在部门既无单位码集合也无部门名 → 提问直接 403「该账号未绑定部门数据权限，请联系管理员配置」。

脱敏：
- 命中敏感列时保留前 1/4 与后 1/4 字符、中间用 `*`，长度不变；≤4 位全掩。
- 血缘传播：`SELECT name, sfzjh AS id_no FROM t`、子查询、CTE、UNION、`SELECT *` 都能把源列的敏感标记带到输出列。
- 管理员查看同一查询返回原文（前端不显示脱敏提示行）。
- 设计内不脱敏：`COUNT(敏感列)`、`LEFT(敏感列,6)` 等函数包裹的派生值。

码表翻译：
- 生效码值 = 列绑定的全局码表 entries + 列级 `enum_dict`（本地覆盖同 key），合并函数 `effective_enum` 同时供提示词与结果层使用。
- SQL 生成侧强制使用 key 原值，结果侧把 key 替换为含义；未在码表中的 key 原样返回；`"11.0"` 这类浮点形态会回退查 `"11"`。
- 有生效码表的列无条件进入选列提示词，所以"休学类异动有多少条"这类问题能被翻译成功：`WHERE ydlbm='11'` → 结果列显示「休学/复学/退学」等含义。
- 改全局码表/列级码值即时生效（每次提问现算），不需要重建向量索引。

只读与系统表：
- 多语句、非 SELECT 根节点、出现 Insert/Update/Delete/Drop/Create/Alter/Merge/Command/Transaction/Commit/Rollback/Grant/Set 任一节点 → `blocked_by_guard`。
- 表带 `information_schema.` / `mysql.` / `pg_` / `sys.` / `performance_schema.` / `dual` 前缀 → 拒绝。

## 6. 会话功能

| 操作 | 行为 | 边界 |
|---|---|---|
| 新建会话 | 前端优先 `POST /api/sessions` 拿 uuid，失败则本地生成 uuid | 会话行在首次提问时才被 `touch` 落库；未提问的新会话不占库 |
| 切换 | 侧栏点击，`sessionId` 存 `localStorage['insightai_sid']` | 切换前销毁 ECharts 实例，避免画布残留 |
| 重命名 | 行内输入框，回车或失焦提交 `PATCH` | 标题 1~60 字；失败在侧栏顶部黄条显示「重命名失败: …」 |
| 删除 | `confirm()` 明示"历史与已归档口径会一并清除，不可恢复" | `chat_session` 置 `deleted=true` 保留供审计，`chat_turn` 硬删；被删会话若再来提问会被复活 |
| 列表 | 按 `updated_at` 倒序，≤50 条，带轮次与「已归档口径」标记 | 跨账号访问返回空列表（history）或 404（改名/删除） |
| 隔离 | 提问时若 session_id 属于他人 → 403「会话不属于当前账号」 | `default` 会话被首个用户认领 |
| 记忆 | 最近 5 轮 ok 明细 + ≥8 轮后压缩口径摘要 | 摘要后台生成，因此侧栏标记与摘要内容晚一拍 |

## 7. 管理页（四个页签，仅管理员可见）

顶部导航：「对话」所有人可见；「语义管理」「全局码值」「指标口径」「权限管理」仅管理员。点左上角产品名回到对话。

### 7.1 语义管理

布局：顶部操作条 + 当前表的列清单（列/类型/说明/枚举码表/敏感/编辑）。

- 表选择器：下拉显示 `表名（注释，N列，码表x/敏感y）`，旁边有筛选框按表名/注释过滤。
- 表级操作：
  - **表注释**：输入框 + 「保存注释」；保存即重嵌入该表向量，立即参与召回。
  - **行级权限列**：下拉选列 + 「保存表设置」；列不存在 → 422；选「（不过滤）」清空。只改注释不会清掉已设的部门列（接口按字段是否提交区分）。
  - **同步元数据**：「同步前缀」输入框（逗号分隔，如 `dwd_,dws_`；空=不过滤）+「同步元数据」按钮。点击后后台线程执行，按钮变「同步中…」，黄条每 2s 刷新进度，完成后自动重载表清单。已有任务在跑时再触发 → 409「已有同步任务在运行」。
- 同步行为（`meta_sync.sync`）：
  - 从业务库 `information_schema` 拉表/列；前缀按表名小写 startswith 匹配，任一命中即保留；过滤后 0 张表直接结束。
  - **只增不覆盖**：新表新增；已存在的表只新增其中不存在的列；已有列的注释/码表/敏感标记一律不动；表注释只补空；业务库已消失的表/列不删除。
  - 新列按正则自动标敏感（`phone|mobile|id_card|idcard|identity|身份证|手机号|salary|薪`）；表名 `dwd|ads|dws` 开头自动归 `trade` 域。
  - 同步范围内所有表及全部列的向量重算（merge-insert）。
- 列级操作：
  - 敏感标记：列清单行上的 checkbox，即时保存。
  - 「编辑」弹窗：**列注释**（保存即重嵌入该列与所在表向量）、**全局码表绑定**（下拉选已建码表，选空=解绑；编码不存在 → 422）、**本地码值**（每行 `码值=含义`，key 为空 → 422）、「从业务库拉取码值」（实跑 `SELECT DISTINCT … LIMIT 50` 填进编辑框供改含义）、「清空」（清本地码值，不动全局绑定）。
  - 弹窗里明示：生效码值 = 全局码值 + 本地码值（本地覆盖同 key）。
- 探测接口对标识符做 `^[A-Za-z0-9_]{1,64}$` 白名单，且用反引号 quoting，因此**只对 StarRocks/MySQL 业务库有效**；PG 业务库需要改这里的引用符。

### 7.2 全局码值

- 列表：编码/名称/码值数/说明/绑定列数；「新增全局码表」「刷新」。
- 新增/编辑：编码（字母/数字/下划线 1~64 位，创建后不可改，重名 409）、名称、码值（每行 `码值=含义`，key 为空 422）、说明。
- **批量绑定**：输入列名（多个用英文逗号分隔，如 `sfsc,XQM`）→「查询匹配」列出所有语义层表中的同名列（大小写不敏感；显示表/列/说明/当前绑定）→ 默认全选，**同名不同义的列要取消勾选** →「绑定选中列」。绑定即时生效。
- 删除：先自动解绑所有引用列再删码表，返回解绑列数；有绑定时前端会先提示「N 个绑定列将自动解绑」。
- 修改码值内容即时作用于所有绑定列（提示词与结果翻译每次现算），无需重建索引。

### 7.3 指标口径

- 列表：指标名/别名/表达式/所属表/粒度/口径说明/操作。
- 新增/编辑字段与校验：
  - 指标名：必填 ≤128 字，唯一（重名 409）。
  - 别名：每行一个，用于识别不同问法。
  - 表达式：必填，聚合 SQL 片段（如 `SUM(pay_amount)`）。
  - 所属表：下拉选自**已同步的元数据表**；表不存在 → 422。
  - 默认条件：每行一个 SQL 片段（如 `sfsc = '0'`），注入提示词时以 AND 拼接。
  - 粒度：daily/monthly/yearly/none（其它值 422）；仅作口径说明，不参与计算。
  - 口径说明：中文描述，进提示词。
- 生效方式：提问召回命中所属表时，该表全部指标注入 SQL 生成提示词（名称/别名/表/粒度/表达式/默认条件/口径），并追加规则 10「必须使用该指标的表达式和默认条件」。未命中所属表不注入；系统里没有任何指标时提示词与无此功能时逐字一致。
- 约束级别：**提示词级**。guard 不校验生成的 SQL 是否真的采用了指标表达式，验收时要展开 SQL 折叠区人工核对。

### 7.4 权限管理（三 tab）

- 部门：编码/名称/上级/单位码集合（一行一个，最多 50）/启用状态。停用或删除时若仍有用户引用 → 409；上级不能是自己。
- 角色：`admin` 勾选项决定能否进管理页 + 是否免脱敏；内置 `admin`/`user` 不可删；取消某角色管理员属性会导致"没有任何可用管理员"时 → 409。
- 用户：口令留空则自动生成，初始口令仅创建响应里可见一次；停用/改角色/删除都有"至少保留 1 个启用管理员"的守卫；重置口令不会让该用户旧令牌失效（见 §8）。

## 8. 账号与登录

- 登录返回 `{token, token_type, expires_in, expires_at, user{…}}`，令牌默认 8 小时。
- 失败策略：账号连错 5 次锁 15 分钟（423 + `Retry-After`），锁定计数在锁定时清零；同一 IP 每分钟 5 次尝试上限（429）。用户名不存在与密码错误返回同一句话「用户名或密码错误」，并且都会走一次 pbkdf2 校验以拉平耗时。
- 口令策略：≥8 位、必须同时含字母和数字、再加"含符号或大小写混合"之一。
- 自助改口令：旧口令错 → 401 且不掉线；成功 → 当前令牌立即吊销 + `pwd_changed_at` 前移，其它设备上的旧令牌全部 401「口令已修改，请重新登录」。
- 登出：吊销 jti（Redis 或进程内存，TTL 等于令牌剩余寿命）。Redis 读失败时**失效放行**（当作未吊销），属于已知取舍。
- 未配 `TOKEN_SECRET` 时进程随机生成，重启即全员重新登录（启动打 WARNING 提醒）。

## 9. 前端错误呈现

- 统一走 `auth.errText()`：优先后端 `detail` 字符串；FastAPI 422 的数组会被拉平成 `字段：错误信息`（多个用「；」连接）；否则退化成 `HTTP <状态码>`。实测改口令空值显示为「new_password：String should have at least 1 character」。
- 任何 401（除改口令弹窗内的 401，它只展示文案不踢人）都会清令牌并回到登录页。
- 无 toast 体系：黄条（侧栏/管理页/编辑弹窗/改口令框）+ 红字（登录框）+ 聊天流内联「请求失败: …」。

## 10. 不在功能范围内

- 表间关系（JOIN 键）元数据与跨主体 JOIN 硬拦截。
- 部门树形继承、主题域参与召回、按域限定可见用户。
- 指标引擎/预计算/物化：指标口径只是提示词约束，不保证执行层采用。
- 语义层表/列删除入口：同步只增不删，残留行需直接清理平台库。
- 结果导出 Excel/PNG、图表二次编辑、看板订阅。
