# InsightAI ChatBI 使用文档

面向业务用户（提问）与管理员（配置）。对应 2026-11-08 版本。

平台接的是高校数据中台业务库，能问什么以「语义管理」页里接入的表为准（当前环境已接入 470 张表，以 `dwd_xb_*` 数据子类为主，覆盖学籍、教职工、单位、异动、课程、班级、成绩、图书、督导、考勤、财务等主题）。常用表举例：

| 表 | 说明 | 可问的内容 |
|---|---|---|
| `dwd_xb_xjjbsj` | 学籍基本数据子类 | 年级、专业、院系、班号、研究方向、导师、是否在校、学历层次 |
| `dwd_xb_jzgjbsj` | 教职工基本数据子类 | 姓名、工号、所在单位、编制/教职工类别、岗位等级、聘任年月 |
| `dwd_xb_xjydsj` | 学籍异动数据子类 | 异动类别（休学/复学/退学）、异动区间 |
| `dwd_xb_dwjbsj` | 单位基本数据子类 | 单位名称、单位码 |
| `dwd_view_ds_kb_kbxx` | 教务课程表 | 课程、课容量、选课相关 |

只能问已接入表覆盖的内容。表里没有的维度，平台会明说"没有对应字段"，不会编一个列名糊弄你。

---

## 1. 登录

1. 浏览器打开平台地址（本机部署默认 `http://localhost:8080`）。
2. 输入管理员分配的账号与口令 → 登录。
3. 顶部右侧显示"显示名 · 部门名 · 数据权限范围"（管理员显示"· 管理员"，普通用户显示"· N 个单位码"）。**这里没有部门名就说明管理员还没给你绑数据权限，提问会被拦**，见 §8 的 403。

口令规则：至少 8 位，必须同时含字母和数字，再满足"含符号"或"大小写混合"之一。忘了口令只能找管理员重置，重置后需要重新登录。

## 2. 怎么问

一句话结构：**统计对象 + 维度 + 指标 + 限定条件**。示例：

- 「按单位统计学籍数量」
- 「休学类的学籍异动有多少条」
- 「教职工总人数」
- 「列出教职工的姓名和身份证号」
- 「按异动类别统计学籍异动数量，用柱状图展示」
- 「按年级统计在校人数」

有效的提问习惯：
- **说清维度和指标**：「按年级统计」比「看看年级」好；后者容易被判成不完整问题。
- **用业务中文说法**，不用列名不用 SQL。列注释里的中文说明（如"所在单位""异动类别码"）就是最好的词表。
- **码值可以只说含义**：说"休学类"，平台会翻成码值（如 `ydlbm='11'`）去查，结果里再把码值显示成"休学/复学/退学"。全局码值（如"有效标识"）同理。
- **管理员定义了指标口径的，直接说指标名或别名**：比如定义了"在校生人数"口径，问「在校生人数是多少」会按统一口径（表达式 + 默认条件）生成 SQL。
- **要图就在问题里点名图型**：柱状图/折线图/饼图/表格。饼图要求结果正好是"1 个类别列 + 1 个数值列"，否则自动退回柱状图或表格。
- 单次问题 ≤500 字；结果最多 1000 行，超过会在答案里标"已截断至上限"，需要更多请缩小范围或改成聚合。

问不动的三类（属于设计，不是 bug）：
- 与数据无关（寒暄、写作、通用常识）→ 固定拒答话术。
- 表里没有该维度 → 「当前数据里没有可以回答该问题的字段：…」，例如「按性别统计学生人数」（学籍表无性别列）。
- 涉及跨主体关联但语义层没有可对齐的业务键 → 结果可能为空，请改用同一主体内的维度提问。

## 3. 看懂回答

每条回答下面依次是：结论句 → 提示行（若有）→ 表格或图表 → 「SQL（生成 → 守卫改写后）」折叠区 → 导出CSV。

- 结论句形态：「共 N 行，已生成柱状图。」/「列名=值」（指标卡）/「查询完成，但没有符合条件的数据（可能受部门权限限制）。」
- 「敏感列已脱敏：xxx」：身份证号等被标了敏感的列，显示成 `411***********0042`（保留前 1/4 后 1/4，长度不变）；**管理员账号看原文**。
- 「码值已翻译为含义：xxx」：单元格显示的是中文含义，SQL 里用的仍是码值。
- 折叠区两条 SQL：橙色是模型生成的原始 SQL，绿色是实际执行的那条（已注入你部门的过滤条件、已加 LIMIT）。**核对口径看绿色这条**；用了指标口径的问题，也在这里核对表达式与默认条件。
- 图表只对最后一条提问渲染；往前翻历史轮次看到的是表格。

## 4. 多轮追问

平台会把上一轮的口径带进下一轮，包括它实际用的表和字段。支持的追问形态：

- 换条件：「再看 2023 级的」
- 加维度：「再按专业拆一次」
- 换指标：「人数改成占全部的比例」→ 注意比例类需要"占比/分布"这类词才会出饼图
- 纯换图：「用饼图展示」「换成折线图」「改成表格」——这类只换图型的问题直接复用上轮口径重跑，不会把你当闲聊拒答
- 追问里省略主语：「那休学的呢」

一个刻意的设计：如果新问题自己已经说全了对象和指标，平台**不会**给它叠加历史的维度或图型，避免"问了个新问题却带着旧过滤条件"。

## 5. 会话管理

- 左侧「会话」列表：显示标题、轮次；有归档口径的会标「· 已归档口径」。
- 新建会话：顶部「新建会话」或侧栏「新建」。新会话在你第一次提问后才真正落库。
- 切换：点标题，聊天区换成该会话的历史。
- 重命名：点行上的「重命名」，输入框改文字，回车或点到别处保存（≤60 字）。默认标题取首次提问前 60 字。
- 删除：点「删除」并确认。会一并清除该会话的历史轮次与已归档口径，**不可恢复**。
- 会话隔离：别人的会话在你这里看不到也进不去；拿别人的会话 ID 提问会被拒（403）。
- 记忆范围：最近 5 轮完整参与改写；更早的轮次会被压缩成"口径摘要"（只保留对象、表列、时间范围、过滤条件、已确认的结论口径，不含任何统计数值）。所以长会话里问"我们最开始定的是哪个范围"能答上，但问"最开始那个数是多少"要重新提问查。

## 6. 导出结果

每条结果右上的「导出CSV」把该条全部行导出成 `insightai_<时间戳>.csv`（带 BOM，Excel 直接双击不乱码）。注意：导出的是**脱敏与翻译之后**的显示值；从历史回放打开的轮次最多 200 行，实时提问最多 1000 行。

## 7. 修改自己的口令

顶部「修改口令」→ 填旧口令 + 新口令两遍 → 提交。
- 旧口令错：提示错误，**不会被踢下线**。
- 成功：提示「口令已修改，请重新登录」，当前设备需要点「重新登录」，其它设备/浏览器的登录状态同时失效。
- 连错 5 次会锁定账号 15 分钟（提示会告诉你还要等多久）。

## 8. 常见提示与自查

| 提示 | 原因 | 你能做什么 |
|---|---|---|
| 「该账号未绑定部门数据权限，请联系管理员配置」 | 账号没绑部门，或部门没有单位码集合 | 找管理员（§9.4） |
| 「当前数据里没有可以回答该问题的字段：…」 | 语义层缺该维度/指标 | 换维度问，或请管理员确认该列是否已在语义层 |
| 「抱歉，我只解答与企业数据分析相关的问题…」 | 被判为无关问题 | 用"按 X 统计 Y"的句式重问 |
| 「查询完成，但没有符合条件的数据（可能受部门权限限制）」 | 你的部门范围里没有数据，或过滤条件太窄 | 放宽条件；或确认数据权限是否覆盖目标单位 |
| 「[blocked_by_guard] …」 | SQL 触发只读/系统表/部门标识护栏 | 正常提问不会出现；出现请带 SQL 折叠区截图找管理员 |
| 「[exec_error] / [engine_error] …」 | 业务库执行失败/超时，或模型未响应 | 稍后重试；持续出现联系管理员（模型或业务库连接问题） |
| 「登录尝试过于频繁，请稍后再试」 | 同一 IP 每分钟超过 5 次登录尝试 | 等 1 分钟 |
| 「登录状态无效：口令已修改，请重新登录」 | 你在别处改过口令 | 重新登录 |
| 界面直接贴出一段英文校验文字 | 请求体不合规模块 | 按「字段：原因」改一下再提交 |

## 9. 管理员操作

管理员除提问外多四个入口：顶部「语义管理」「全局码值」「指标口径」「权限管理」。点左上角产品名随时回到对话。

### 9.1 语义管理（决定"能问什么、怎么问对")

**接入新表（同步元数据）**：
1. 顶部「同步前缀」填要接入的表名前缀，多个用逗号分隔（如 `dwd_,dws_`）；留空 = 全量同步库里所有表。**不是库里所有表都该开放提问，按需填前缀**。
2. 点「同步元数据」→ 按钮变「同步中…」，黄条实时显示进度（第几张表、向量化多少条），完成后自动刷新表清单。表多时向量化要几分钟，期间不要重复点（会提示已有任务在运行）。
3. 同步是"只增不覆盖"：已接入的表不会被改动，你手工维护的注释、码表、敏感标记都安全；业务库里删掉的表不会自动消失（残留清理见《部署文档》§8）。

**逐表/逐列维护**（直接决定问答质量）：
1. 表选择器选表（可用筛选框按表名/注释过滤），看列数、码表列数、敏感列数。
2. **表注释**：顶部输入框写清这张表是干什么的 →「保存注释」。保存即更新召回向量，立即生效。
3. **列注释**：点列行的「编辑」→ 弹窗顶部「列注释」写清业务中文含义 → 保存。这是召回与选列的最重要依据，保存后自动更新向量，**不需要再跑任何重建索引脚本**。
4. **码表**：两条路——
   - 跨表通用的码（如"有效标识"）：去「全局码值」建码表再绑定（见 §9.2），一处维护处处生效。
   - 本列特有的码：在编辑弹窗里绑定全局码表（可选）+ 填本地码值（每行 `码值=含义`）。「从业务库拉取码值」可实跑 `SELECT DISTINCT` 带回最多 50 个真实值供你填含义。**生效码值 = 全局 + 本地，本地覆盖同 key**。
5. **敏感列**：列清单行上勾选。勾选后普通用户看到部分掩码，管理员看原文。同步时已按关键词自动标了一部分（身份证/手机号/薪资等），人工复核补齐。
6. **行级权限列（表级设置）是行级权限的开关**：顶部「行级权限列」选列 →「保存表设置」。**不设置该表就不受部门裁剪（任何部门的人都能看全表）；新同步的表默认都没设置，开放给普通用户前务必逐表确认。**

### 9.2 全局码值（跨表通用码表）

- 「新增全局码表」：编码（字母/数字/下划线，创建后不可改）、名称、码值（每行 `码值=含义`）、说明。
- **批量绑定**：点码表行的「批量绑定」→ 输入列名（多个用逗号分隔，如 `sfsc`）→「查询匹配」列出所有表里的同名列 → 勾选要绑的列（**同名不同义的列取消勾选**）→「绑定选中列」。
- 也可以在语义管理的列编辑弹窗里逐个绑定/解绑。
- 改码值内容立即对所有绑定列生效，不用重建索引。删除码表会自动解绑所有引用列。

### 9.3 指标口径（统一"同一个指标怎么算"）

- 「新增」：指标名（唯一）、别名（每行一个，覆盖不同问法）、表达式（如 `COUNT(*)`、`SUM(xf)`）、所属表（只能选已同步的表）、默认条件（每行一个，如 `sfsc = '0'`）、粒度、口径说明。
- 用户提问命中所属表时，平台把指标口径注入生成提示词，要求模型按表达式和默认条件出 SQL。
- **这是强提示不是硬保证**：重要口径上线后，用几种问法实测并展开 SQL 折叠区核对；没命中所属表（问法与注释不匹配）时指标不会生效，先回去补注释。

### 9.4 权限管理（决定"谁能看哪些数据")

三个 tab：部门 / 角色 / 用户。

- **部门**：`code` 唯一、创建后不可改；「单位码集合」一行填一个业务库里的单位码，1 个→等值过滤，多个→`IN` 过滤，留空→该部门用户不做行级过滤（普通用户留空时提问会被 403 拦）。上限 50 个。停用或删除部门时若仍有用户引用会被拒。
- **角色**：内置 `admin`（管理员）与 `user`（普通用户），不可删除。勾选"管理员"= 可进四个管理页 **且查询结果不脱敏**，这两件事绑在一起，别随手勾。系统必须至少保留 1 个启用的管理员，否则改动会被拒。
- **用户**：新建时口令留空则自动生成，**初始口令只在创建成功那一行显示一次**，请立即转交。改部门=改数据权限、改角色=改能力，都即时生效，用户无需重新登录。停用账号会立即让其所有登录状态失效。删除用户是硬删，其历史会话记录保留。

### 9.5 新用户开通最短路径

1. 权限管理 → 部门 → 确认目标部门的单位码集合正确（没有就新建）。
2. 语义管理 → 确认该用户要问的表已设置行级权限列（§9.1 第 6 条）。
3. 权限管理 → 用户 → 新建：用户名、显示名、部门、角色（一般 `user`）、口令留空自动生成。
4. 把一次性初始口令交给用户，提醒其登录后用「修改口令」换成自己的。

## 10. 使用侧的限制与约定

- 结果上限 1000 行、查询超时 10 秒：大表请聚合或加条件。
- 图表只在最新一轮显示；要图就在提问时点名图型。
- 导出的是显示层数据（脱敏 + 码值翻译后），不是原始明细。
- 历史审计（谁问了什么、执行了哪条 SQL、返回多少行、耗时）由服务端保留，管理员可查数据库；平台界面不提供审计页。
